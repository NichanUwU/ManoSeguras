# MercadoSeguro

MercadoSeguro es una plataforma orientada a facilitar compras y ventas más confiables, con foco en la seguridad, la transparencia y la protección de las personas usuarias.

> **Estado del proyecto:** En desarrollo 🚧

## 📋 Descripción

El objetivo de MercadoSeguro es ofrecer un espacio sencillo y seguro para conectar a compradores y vendedores, reduciendo riesgos durante el proceso de publicación, comunicación y negociación de productos o servicios.

## ✨ Características

- Publicación y consulta de productos o servicios.
- Búsqueda de ofertas de manera sencilla.
- Información clara para ayudar a tomar mejores decisiones.
- Comunicación entre compradores y vendedores.
- Enfoque en buenas prácticas de seguridad y confianza.

> Las funcionalidades pueden cambiar a medida que avance el desarrollo del proyecto.

## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/NichanUwU/ManoSeguras.git
cd ManoSeguras
```

Instala las dependencias según el gestor utilizado por el proyecto y ejecuta los comandos definidos en la documentación o en los archivos de configuración del repositorio.

## 💻 Uso

1. Inicia la aplicación siguiendo las instrucciones de instalación.
2. Explora las publicaciones disponibles.
3. Crea una publicación o contacta con la persona vendedora.
4. Verifica siempre la información antes de concretar una operación.

## 🔐 Recomendaciones de seguridad

- No compartas contraseñas, códigos de verificación ni información bancaria sensible.
- Comprueba la identidad y los datos de la otra persona antes de realizar un pago.
- Desconfía de ofertas que parezcan demasiado buenas para ser verdad.
- Utiliza los canales oficiales de la plataforma para comunicarte.
- Reporta cualquier actividad sospechosa.
